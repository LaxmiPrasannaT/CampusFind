# 🎒 CampusFind

A web-based **Campus Lost & Found Management System** developed to simplify the process of reporting and recovering lost and found items within a college campus.

---

## 📌 Features

- 👤 User Registration & Login
- ✅ Roll Number & Mobile Number Validation
- 📷 Report Lost & Found Items with Image Upload
- 👨‍💼 Admin Approval System
- 🔍 Search & Category Filter
- 📝 My Reports Dashboard
- 🔐 Return Verification Code
- 🚫 Duplicate Report Prevention
- 📱 Responsive User Interface

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Supabase
